# 🌾 Krishi Ratna – AI Powered Smart Farming Platform

Krishi Ratna is an AI-powered smart farming platform designed to assist farmers with intelligent agricultural solutions. The platform provides AI crop advisory, pest & disease detection, weather monitoring, and market insights to support better agricultural decision-making.

The goal of Krishi Ratna is to make modern farming assistance accessible through technology and improve agricultural productivity using AI-powered services.

---

### 🤖 AI Crop Advisory
Get AI-powered agricultural recommendations and farming guidance.

Features:

## ⚙ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/CarismaticX/KrishiRatna.git

cd KrishiRatna
```

---

### Client Setup

```bash
cd client

npm install

npm run dev
```

Client runs at:

```bash
http://localhost:5173
```

---

### API Setup

```bash
cd api

npm install

node server.js
```

API runs at:

```bash
http://localhost:5000
```
